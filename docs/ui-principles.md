# Принципы интерфейса Gifter

Gifter — рабочее B2B-приложение для служб отеля, а не маркетинговый сайт. Каждое решение по интерфейсу проверяется вопросом: **помогает ли это сотруднику быстрее и без ошибок сделать работу?**

## Приоритеты (решение владельца, 22.10.2026)

1. **Иерархия информации** — главное (номер, статус, сумма, срок, кто) видно сразу; второстепенное — во вкладках и описаниях.
2. **Скорость работы** — меньше кликов и переходов: действия на странице записи, ссылки с плиток на отфильтрованные списки, глобальный поиск `Ctrl+K`, SPA-навигация.
3. **Плотность данных** — таблицы во всю ширину, по 25 строк, с чередованием; никаких пустых блоков «ради воздуха». Пустые таблицы на главной не показываются.
4. **Понятные статусы** — у каждого статуса один цвет везде: серый — черновик/неактивно, зелёный — активен/оплачено, синий — бронь/в работе, жёлтый — ждёт действия, красный — аннулирован/срочно. Цвет плитки на главной загорается только когда есть что делать.
5. **Предсказуемая навигация** — постоянные группы меню: Продажи → Деньги → Каталог → Администрирование; одинаковое расположение действий на всех карточках (основные — кнопками, редкие — в «Ещё», исправления администратора — отдельная красная кнопка).
6. **Минимальная когнитивная нагрузка** — пользователь видит только свои разделы и кнопки (по роли); поля, которые ему нельзя менять, не показываются, а не блокируются.
7. **Предотвращение ошибок** — бизнес-правила проверяются в системе, а не только в интерфейсе; подтверждение для необратимых действий; обязательная причина для исключений; предупреждение о несохранённых изменениях; каждое действие в транзакции.

## Чего не делаем

- Декоративные иллюстрации, крупные «hero»-блоки, анимации, карточки там, где нужна таблица.
- Внешние сервисы в интерфейсе (аватары, шрифты, трекеры): аватар — инициалы, шрифт — локальный.
- Скрытие важных статусов за наведением мыши или лишними кликами.

## Где это в коде

- `app/Providers/Filament/AdminPanelProvider.php` — ширина, SPA, предупреждение о несохранённых данных, транзакции, `Ctrl+K`, локальные аватары.
- `app/Providers/AppServiceProvider.php` — общие настройки таблиц.
- `app/Enums/*Status.php` — цвета статусов в одном месте.
- `app/Filament/Widgets/` — главная по ролям: только то, что требует действия.
