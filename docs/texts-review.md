# Ревизия текстов — пакет 1: витрина сайта (на утверждение)

Тон: тёплый, премиальный, короткий, на «вы». Юридические тексты (политика, условия) не меняем — только стиль, по вашей отдельной команде. Казахский и английский — моя подготовка, перед выкатом их должен прочитать носитель языка. Что-то не нравится — вычеркните или напишите свой вариант, остальное применю как есть. Пакеты 2 (письма и PDF) и 3 (админка) — следующими.

Строки, которых нет в таблице, остаются как есть (в т. ч. «Подарите время, которое запомнится», «Подарок, который не будет пылиться на полке», меню, «Выберите сертификат», «Связаться с нами»).

## Вопросы по применению

- В «Описании для поиска» убрано слово «спа»: в составе пакетов спа нет. Если есть — верните.
- «Заказ» вместо «заявка» на сайте: клиент покупает подарок; внутри системы «заявка с сайта» остаётся.
- Блоки «Вопросы и ответы» и «Условия сертификата» (стандартные тексты на трёх языках) — в пакете 2, вместе с письмами; политика конфиденциальности — по вашей отдельной команде.
- Тексты, которые вы уже меняли в «Настройках сайта → Контент» и в заголовке главной, не перезаписываются: меняются только значения по умолчанию.
