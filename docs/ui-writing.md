# Тексты интерфейса: правила

1. Язык сотрудника: что сделать и что произойдёт. Без внутренних терминов (токен, API, снимок, ID). Кнопки — глагол: «Выставить счёт», «Отметить использованным».
2. Единый словарь: Заказчик, Получатель, Бронь, Сертификат, Использован, Допуслуга, Сверка, Продавец, Пакет сертификата, Цена продажи, Себестоимость. «PMS» оставляем.
3. Размеры (проверяет `tests/Feature/UiTextLimitsTest.php`):

| Элемент | Знаков |
|---|---|
| Пункт меню | ≤ 24 |
| Заголовок колонки | ≤ 20 |
| Кнопка | ≤ 28 |
| Подпись поля | ≤ 40 (тест допускает до 54 для составных) |
| Подсказка под полем | ≤ 120 |
| Описание окна | ≤ 200 |
| Уведомление | ≤ 90 |
| Плитка: название / пояснение | ≤ 28 / ≤ 50 |
| Placeholder | ≤ 30 |

4. Без восклицательных знаков; кавычки «ёлочки»; предложение с заглавной буквы.
5. Новый русский текст сразу получает ключ в `lang/kk.json` и `lang/en.json` (пока нет перевода — показывается русский, см. `docs/i18n.md`).
