# Фаза 5 — исполнение услуг

Сертификат остаётся одним неделимым пакетом и гасится только целиком. Но услугам внутри него нужна разная подготовка: завтрак ничего не требует, ужин — столик на время и подтверждение ресторана, канатка — билеты, трансфер — машина к назначенному часу. Для таких услуг ведутся **заявки на исполнение**.

## Решения владельца (27.10.2026)

| Вопрос | Решение |
|---|---|
| Кто ведёт заявки | Front Office / Бронирование и менеджер продаж. Остальные видят статусы во вкладке «Исполнение» сертификата |
| Когда появляются заявки | При отметке брони |
| Погашение с невыполненными заявками | Разрешено с предупреждением: в окне погашения — список невыполненных; они закрываются как «Отменено» с причиной |

## Какие услуги

Признаки задаются в каталоге (фаза 3) и копируются в сертификат при продаже:

- *требует подготовки* — по услуге создаётся заявка;
- *нужны дата и время* — без даты и времени заявку нельзя подтвердить;
- *нужно подтверждение поставщика* — выполненной услугу можно отметить только после «Подтверждено».

## Статусы заявки

```
Ожидает → Заявка отправлена → Время назначено → Подтверждено → Выполнено
                      любой шаг до «Выполнено» → Отменено (с причиной)
```

- **Отправить заявку** — текст для поставщика подставляется сам (номер сертификата, гость, услуга, когда, срок действия) и сохраняется в заявке; в окне — контакты и условия поставщика. Отправка — любым удобным способом: интеграций с поставщиками нет.
- **Назначить время / Перенести** — дата в пределах срока сертификата, время ЧЧ:ММ. Перенос подтверждённой услуги снимает подтверждение.
- **Подтверждено** — с комментарием (кто подтвердил, номер у поставщика).
- **Выполнено** — только во время проживания (после «Заезд»). Это не погашение: сертификат остаётся «В использовании».
- **Отменить** — с причиной.

Заявки не удаляются; каждое изменение — в истории сертификата.

## Связь со статусом сертификата

| Сертификат | Заявки |
|---|---|
| Отмечена бронь (и после «Заезд») | По каждой услуге «требует подготовки» без открытой заявки — новая «Ожидает» |
| Снята бронь | Открытые → «Отменено: Бронь снята»; при новой брони — новые заявки, старые остаются в истории |
| Погашен | Открытые → «Отменено: Сертификат погашен, услуга не выполнена» |
| Истёк / аннулирован / возврат | Открытые → «Отменено» с причиной |

При обновлении базы уже забронированные и заехавшие сертификаты получают заявки «Ожидает».

## Где работать

- **Продажи → Исполнение услуг** — очередь для Front Office и менеджера: по умолчанию открытые заявки; фильтры «Требует действия», «Когда» (сегодня, завтра, 7 дней, без даты), статус, поставщик. В меню — счётчик заявок, ждущих отправки.
- **Вкладка «Исполнение»** в сертификате — те же заявки и действия.
- **Главная Front Office** — «Заявки ждут отправки», «Ждут подтверждения», «Услуги сегодня»; у менеджера — «Заявки ждут отправки».

Сам экран заездов («Ближайшие заезды» и готовность «Готов / Требует действия») — фаза 6.
