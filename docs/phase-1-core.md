## Сущности

`User`, `Customer` (покупатель), `Recipient` (получатель), `Certificate`, `CertificateItem`, `Package` + `PackageItem`, `Service`, `ServicePrice`, `Payment`, `CertificateHistory`, `AuditLog`.

## Жизненный цикл сертификата

```
DRAFT ──выпуск──▶ ACTIVE ──▶ RESERVED ──▶ IN_USE ──▶ USED
  │                 │  ▲         │
  │                 │  └─────────┘ (бронь снята)
  │                 ├──▶ EXPIRED (ежедневная команда)
  └──▶ CANCELLED ◀──┴── RESERVED
```

- **DRAFT** — номер присвоен сразу (нужен для счёта), состав и реквизиты можно менять, пока нет открытых счетов.
- **Выпуск** (DRAFT → ACTIVE) — только если есть услуги, сумма полностью оплачена и срок не истёк.
- **USED** — использование всего сертификата целиком; частичного использования нет.
- **USED, EXPIRED, CANCELLED** — конечные. Исключения по истёкшим сертификатам — фаза 7 (Finance), исходная история не переписывается.
- Аннулирование — только с причиной и после отмены неоплаченных счетов. Оплаченный сертификат аннулируется только через возврат с согласованием Финансов (фаза 2).

## Правила, закреплённые в коде и тестах

- Сертификат, строки состава выпущенного сертификата, счета, история и журнал аудита физически не удаляются (исключение на уровне модели).
- История и аудит — только вставка.
- Цена услуги берётся на дату продажи и копируется в строку (`unit_price`, `service_name_snapshot`, `price_version_id`); смена каталога или прайса её не меняет. Версию цены, уже попавшую в сертификаты, переписать нельзя.
- Новая версия цены закрывает предыдущую открытую; пересечения периодов запрещены.
- Пакет — шаблон: при применении состав копируется, последующие правки пакета на сертификаты не влияют.
- Номер — из счётчика под блокировкой строки + уникальный индекс. По умолчанию `GIF-000001`, сквозная нумерация; если в шаблон добавить год, нумерация станет годовой.
- Счёт можно выставить только по черновику и не больше неоплаченного остатка; оплаченный счёт отменить нельзя.
- Изменение срока действия — только с причиной, старые даты остаются в истории.
- `php artisan gifter:expire-certificates` (ежедневно в 00:10) переводит ACTIVE с прошедшим сроком в EXPIRED.
