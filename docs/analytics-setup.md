# Аналитика сайта: как подключить и смотреть конверсию

Витрина: главная `/` → страница пакета `/order/{id}` → «Спасибо» `/order/thanks`. Счётчики подключаются в «Настройки сайта → Оформление → Аналитика и связь».

## Что уже отправляет сайт

| Действие посетителя | Google Analytics 4 | Яндекс.Метрика | Meta Pixel |
|---|---|---|---|
| Открыл любую страницу | `page_view` (автоматически) | просмотр (автоматически) | `PageView` |
| Открыл страницу пакета | `view_item` (название, сумма, KZT) | — (виден как просмотр страницы) | `ViewContent` |
| Начал заполнять форму | `form_start` | цель `form_start` | — |
| Нажал «WhatsApp» / «Позвонить» | `contact_click` | цель `contact_click` | `Contact` |
| **Отправил заказ** (главная конверсия) | `order_submitted` | цель `order_submitted` | `Lead` |

Конверсия «заказ отправлен» уходит **один раз** — только сразу после реальной отправки формы. Обновление страницы «Спасибо», прямой заход на неё и боты в счёт не идут. Персональные данные клиента в счётчики не передаются.

## 1. Получить идентификаторы
- **GA4:** analytics.google.com → Администратор → Потоки данных → Веб → ваш сайт → «Идентификатор показателя» вида `G-XXXXXXXXXX`.
- **Метрика:** metrika.yandex.ru → «Добавить счётчик» (адрес сайта) → номер счётчика (цифры).
- **Meta Pixel:** business.facebook.com → Events Manager → Источники данных → Пиксели → «Создать» → ID из 15–16 цифр.

Введите все три в «Настройки сайта → Оформление → Аналитика и связь» и сохраните.

## 2. Проверить, что данные идут (10 минут)
Откройте сайт со своего телефона **с меткой** `?utm_source=test&utm_medium=check&utm_campaign=setup` (например, `https://ваш-сайт/?utm_source=test&utm_medium=check&utm_campaign=setup`), откройте страницу пакета, нажмите «WhatsApp», начните и отправьте заказ. Потом в «Продажи → Заявки с сайта» отклоните тестовый заказ с причиной «тест».
- **GA4:** Отчёты → «В реальном времени» (видно сразу); для подробной проверки — расширение Google Tag Assistant.
- **Метрика:** Отчёты → Мониторинг (данные за несколько минут).
- **Meta:** расширение Meta Pixel Helper (значок должен быть зелёным) и Events Manager → «Тестовые события» (вставьте адрес сайта).

## 3. Настроить цели (один раз)
- **GA4:** после первого теста события появятся в «Администратор → События» (до 24 часов). Включите «Ключевое событие» у `order_submitted` (заказ) и `contact_click` (обращение).
- **Метрика:** Настройка → Цели → «Добавить цель» → тип «JavaScript-событие» → идентификатор `order_submitted` (название «Заказ отправлен»); то же для `contact_click` («Клик связи») и `form_start` («Начал форму»).
- **Meta:** события `Lead` и `Contact` появятся в Events Manager. В рекламе выбирайте цель оптимизации «Лиды». Подтвердите домен (Brand Safety → Domains) и в «Приоритете событий» расставьте Lead → Contact → ViewContent → PageView.

## 4. Где смотреть конверсию
**Воронка «главная → пакет → заказ»**
- **GA4:** Исследования → «Исследование воронки». Шаг 1 — `page_view`, адрес страницы равен главной; шаг 2 — `view_item`; шаг 3 — `form_start`; шаг 4 — `order_submitted`. Конверсия сайта = пользователи шага 4 / шага 1. Отток между шагами показывает, где теряются люди.
- **Метрика:** Цели → «Составная цель» из шагов: просмотр страницы пакета (URL содержит `/order/`) → цель `form_start` → цель `order_submitted`. Отчёт «Конверсии» разбивает её по источникам.
- **Meta:** Ads Manager → колонки «Лиды», «Цена за лид», «Просмотры контента».

**Ключевые показатели**
- Конверсия в заказ = заказы / сессии.
- Доля обращений = `contact_click` / сессии (клиенты, которым проще написать, чем заполнить форму).
- Цена заказа = расход на рекламу / заказы.

## 5. Настоящая конверсия — в Gifter
Заказ на сайте ≠ продажа: менеджер связывается, клиент оплачивает.
- «Продажи → Заявки с сайта» → блок «Воронка продаж с сайта»: заявки → оформлены → оплачены → выпущены → использованы, **и таблица «По источникам»** — сколько заказов, оплат и выпущенных сертификатов принёс каждый источник (UTM-метка, иначе сайт-источник, иначе «Прямой заход»). Колонка «Источник» есть и в списке заявок.
- «Деньги → Аналитика» — деньги, канал «Сайт».
- Сквозная конверсия = оплаченные заказы / сессии GA4 за тот же период; цена продажи = расход на канал / оплаченные заказы.

## 6. Рекламные ссылки с метками
К каждой рекламной ссылке добавляйте UTM: `?utm_source=instagram&utm_medium=cpc&utm_campaign=ny2026`
- `utm_source` — где реклама (instagram, google, telegram, newsletter), `utm_medium` — тип (cpc, social, email), `utm_campaign` — кампания.
- Метки запоминаются на время визита и сохраняются в заказе: источник виден и в аналитике, и в Gifter. В Instagram/Facebook включите «Параметры URL» в настройках объявления.
- Смотреть: GA4 «Привлечение → Привлечение трафика», Метрика «Источники → Источники, сводка».

## 7. Чистота данных
- **Свои визиты не считать.** Сотрудник один раз открывает сайт с адресом `https://ваш-сайт/?notrack=1` — в этом браузере счётчики больше не грузятся и события гасятся (вернуть: `?notrack=0`). Делать на каждом рабочем устройстве. Дополнительно: GA4 → Потоки данных → «Настроить параметры тега» → «Определить внутренний трафик» (IP отеля) и фильтр данных; Метрика → Настройка → Фильтры → исключить IP.
- **Тестовые заказы** отклоняйте с причиной «тест», чтобы они не попали в отчёты.
- **Занижение 10–30 %** из-за блокировщиков рекламы и режимов приватности браузеров — это нормально; ориентируйтесь на динамику, а деньги сверяйте по Gifter.
- **Задержки:** GA4 «В реальном времени» — сразу, обычные отчёты — до 24–48 часов; Метрика и Meta — минуты.
- **CSP.** Сайт работает с политикой безопасности `CSP_MODE=report`: пока ничего не блокируется. Перед `CSP_MODE=enforce` проверьте журнал «CSP: нарушение» — не блокируются ли хосты Google, Яндекс и Meta.
- **Согласие посетителя.** По вашему решению пиксель и счётчики грузятся сразу, без баннера «Принять»; в политике конфиденциальности это указано. Если появятся требования по согласию — добавим баннер.

## 8. Ритм
Раз в неделю (10 минут): сессии → заказы → конверсия → источники → оплаты в Gifter → цена заказа. Раз в месяц: сравнить каналы по цене оплаченного заказа и отключить слабые.
