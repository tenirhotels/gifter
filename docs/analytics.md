# Аналитика

Страница «Деньги → Аналитика» (право `analytics.view`: администратор, директор по продажам, Финансы). Персональных данных клиентов нет.

## Три разреза
- **Продажа** — по дате продажи (`sold_at`), платные выпущенные сертификаты без аннулированных.
- **Оплата** — по дате оплаты платежа, за вычетом выплаченных возвратов.
- **Использование** — по заезду по брони, а если брони нет — по дате отметки «Использован» в истории. У перенесённых без брони дата неизвестна: они учтены в итогах «Всё время» (плашка «Данные об использовании неполные»), но не попадают в графики по месяцам. После `gifter:import-check-bookings` часть дат появится.
- **Бесплатные** — отдельно: количество и расход (маркетинговая себестоимость). У перенесённых расход неизвестен.

## Период и сравнение
Пресеты «Этот год», «Прошлый год», «Последние 12 месяцев», «Всё время» и любой год из данных. Периоды до 24 месяцев — по месяцам, длиннее — по годам. Переключатель «Сравнить с прошлым периодом» показывает динамику (рост — зелёный, спад — красный; для расхода на бесплатные наоборот). Для «Всё время» сравнения нет.

## Блоки
Ключевые числа с мини-графиками (продано, оплачено, использовано и доля, бесплатные, **обязательства** — действующие непогашенные продажи на сегодня, аннулировано); график «Продажа, оплата и использование» (подсказки с «₸», нарастающий итог по клику в легенде); платные и бесплатные; популярные пакеты; каналы; сезонность; таблица по годам; «судьба сертификатов по году продажи» (использованы, истекли, аннулированы, ещё действуют). Если за период нет данных — понятное пустое состояние. «Скачать CSV» — таблица текущего периода (UTF-8, разделитель «;»).

## Как считается
`App\Services\AnalyticsReport` + `App\Support\AnalyticsPeriod`; результат кэшируется на минуту (ключ включает отпечаток данных). Тесты — `AnalyticsTest`.
